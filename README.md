# Gats amb drama

Galeria responsive de 12 fotografies. Obre `index.html` en un navegador per veure-la.

El layout es construeix amb Flexbox i CSS propi, sense llibreries:

- 1 columna per sota de 600 px
- 2 columnes entre 600 i 839 px
- 3 columnes a partir de 840 px, amb imatges de fins a 300 × 300 px

Les fotografies es retallen proporcionalment per omplir cada espai quadrat, sense deformar-se.
